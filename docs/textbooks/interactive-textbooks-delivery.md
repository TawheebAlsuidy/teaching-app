## 3. المعمارية الهندسية متعددة الطبقات (The 6-Layer Architecture)

يعتمد المحرك الموحد المطور للكتب التفاعلية على 6 طبقات برمجية متزامنة ومتناغمة:

```
+-------------------------------------------------------------------+
| Layer 6: Offline Cache & State Persistence (localStorage / prefs) |
+-------------------------------------------------------------------+
| Layer 5: Assessment & Ministerial Question Bank (MCQ/Reasons/Sol) |
+-------------------------------------------------------------------+
| Layer 4: Interactive 3D Labs & Simulations Engine (Three.js r128)  |
+-------------------------------------------------------------------+
| Layer 3: Dynamic Multi-Tier Explanation Bottom Sheet (3 Levels)    |
+-------------------------------------------------------------------+
| Layer 2: Interactive SVG & Responsive Hotspot Bounding Boxes      |
+-------------------------------------------------------------------+
| Layer 1: High-DPI Page Canvas / Crisp Rendered Ministerial Book    |
+-------------------------------------------------------------------+
```

### تفصيل الطبقات:
1. **الطبقة الأولى (Layer 1 - Crisp Page Canvas):**
   عرض فائق النقاء لصفحات الكتاب الوزاري بأبعاد ثابتة بنسبة $1 : 1.412$، مع محاذاة تلقائية وتجاوب كامل مع مختلف أحجام شاشات الهواتف والأجهزة اللوحية دون تشويه الخطوط.
2. **الطبقة الثانية (Layer 2 - Hotspot Overlay):**
   طبقة تراكبية ذكية قائمة على النسب المئوية للمستطيلات ($x, y, w, h$) تلتقط لمسات الطالب على الرسومات التشريحية، الدوائر الكهربائية، والمعادلات الرياضية وتبرزها بتأثير بصري أنيق.
3. **الطبقة الثالثة (Layer 3 - 3-Level Explanations Bottom Sheet):**
   شاشة سفلية تفاعلية منبثقة تقدم الشرح بثلاثة مستويات تربوية:
   - **المستوى المبسط:** صياغة سهلة تلتقط جوهر الفكرة بأسلوب شيق.
   - **المستوى المنهجي:** الصياغة المعتمدة في الكتاب الوزاري بالتعريفات الدقيقة والمعادلات.
   - **المستوى المتعمق:** ربط المفهوم بالواقع الميداني، التطبيقات الطبية والهندسية، وأسئلة الاختبارات الوزارية المؤتمتة.
4. **الطبقة الرابعة (Layer 4 - Three.js 3D Interactive Labs):**
   معامل افتراضية ومجسمات 3D تفاعلية مدمجة:
   - **الفيزياء:** محاكي المقذوفات في بعدين، دينامو التيار المتردد، رنين دوائر RLC، ونموذج بور الذري.
   - **الأحياء:** مجسم ثلاثي الأبعاد للعصبون والتشابك العصبي، تشريح العين البشرية والأذن، ونموذج الحلزون المزدوج لجزيء DNA ومربع بانيت الوراثي.
5. **الطبقة الخامسة (Layer 5 - Ministerial Assessment Bank):**
   بنك أسئلة وزاري مؤتمت شامل مع تقديم تغذية راجعة فورية، وشرح أسباب صحة أو خطأ كل خيار من الخيارات الأربعة (Distractor Rationales).
6. **الطبقة السادسة (Layer 6 - Offline Persistence & Native Bridge):**
   حفظ تقدم الطالب تلقائياً في قراءة الصفحات ومعدل إنجاز الاختبارات عبر `localStorage`، مع جسر تواصل أصيل `window.ThakerBridge.returnToHome()` للتنقل السلس مع نظام أندرويد.

## 4. تعليمات تجميع وبناء تطبيق أندرويد (APK Build Guide)

تم تحديث سكربت البناء `build_apk.py` ليتعرف تلقائياً على بيئة العمل الحالية، ويقوم بنسخ كافة الأصول التفاعلية وصفحات الكتابين وحزم البيانات إلى مسار `assets` أثناء مرحلة التجميع:

### المتطلبات الأساسية للبيئة الحاضنة:
- نظام تشغيل Linux أو Android Termux أو بيئة خادم CI/CD.
- حزمة أدوات أندرويد (Android Build Tools): `aapt2` و `d8` و `zipalign` و `apksigner`.
- مترجم الجافا `javac` ومسار `android.jar` (API 28 أو أحدث).
- بايثون 3.8 فما فوق.

### أمر التجميع المباشر:
```bash
python3 build_apk.py
```

### ما يقوم به السكربت آلياً:
1. يكتشف مسار المشروع الحالي وينشئ بيئة البناء المؤقتة.
2. ينسخ ملفات `physics-12th-book.html` و `biology-12th-book.html`.
3. ينسخ مجلدات البيانات `data/curriculum/grade12/` وصور الصفحات `assets/curriculum/grade12/`.
4. يترجم ملفات الجافا بما فيها `MainActivity.java` و `LabActivity.java`.
5. ينشئ حزمة APK، يقوم بمحاذاتها عبر `zipalign`، وتوقيعها عبر `apksigner`.
6. يخرج الحزمة النهائية الجاهزة للتثبيت في المجلد المخصص.
